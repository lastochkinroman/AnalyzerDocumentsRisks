# Анализатор Рисков Документов

> Telegram-бот, который читает ваши договоры и находит в них подводные камни

Отправьте боту договор или любой документ — он найдёт, где могут быть проблемы с деньгами, юридические косяки или непонятные обязательства.

## Что умеет

- Читает PDF и DOCX файлы
- Ищет три типа проблем:
  - **Финансовые** — странные условия оплаты, непонятные штрафы
  - **Юридические** — устаревшие законы, отсутствие нужных ссылок
  - **Операционные** — кто за что отвечает, как всё контролировать
- Анализирует через GigaChat
- Работает на русском

## Установка

**1. Поставьте зависимости:**
```bash
pip install -r requirements.txt
```

**2. Создайте `.env` файл:**
```env
TELEGRAM_BOT_TOKEN=ваш_токен_бота
GIGACHAT_TOKEN=ваш_токен_gigachat
```

Токены:
- Telegram — [@BotFather](https://t.me/botfather), команда `/newbot`
- GigaChat — зарегистрируйтесь на платформе и получите API токен

**3. Запустите:**
```bash
python main.py
```

## Как пользоваться

1. Напишите боту `/start`
2. Отправьте PDF или DOCX документ
3. Получите список рисков с объяснениями

Бот сам всё скачает, прочитает и разберёт.
