# Анализатор Рисков Документов

Telegram бот для автоматического анализа документов на предмет потенциальных рисков с использованием искусственного интеллекта GigaChat.

## Возможности

- 📄 Анализ документов в форматах PDF и DOCX
- 🔍 Автоматическое выявление трех типов рисков:
  - **Финансовые риски** (неясные условия оплаты, отсутствие штрафов)
  - **Юридические риски** (отсутствующие ссылки, устаревшие нормы)
  - **Операционные риски** (неясные обязанности, отсутствие механизмов контроля)
- 🤖 Интеллектуальный анализ с помощью GigaChat
- ⚡ Быстрая обработка документов
- 🇷🇺 Полностью русскоязычный интерфейс

## Установка

### Требования
- Python 3.8+
- Аккаунт Telegram Bot (получить у [@BotFather](https://t.me/botfather))
- Токен GigaChat API

### Шаги установки

1. **Клонируйте репозиторий:**
   ```bash
   git clone <repository-url>
   cd doc-risk-analyzer
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Настройте переменные окружения:**
   Создайте файл `.env` и добавьте:
   ```
   TELEGRAM_BOT_TOKEN=ваш_токен_бота
   GIGACHAT_TOKEN=ваш_токен_gigachat
   ```

## Настройка

### Получение токена Telegram Bot
1. Напишите [@BotFather](https://t.me/botfather) в Telegram
2. Используйте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен в `.env`

### Получение токена GigaChat
1. Зарегистрируйтесь на платформе GigaChat
2. Получите API токен для корпоративного доступа
3. Добавьте токен в `.env`

## Запуск

```bash
python main.py
```

Бот будет запущен и готов к работе. Используйте команду `/start` в Telegram для начала работы.

## Использование

1. **Запустите бота** командой `/start`
2. **Отправьте документ** в формате PDF или DOCX
3. **Получите анализ** рисков в документе

Бот автоматически:
- Скачает и обработает документ
- Извлечет текстовое содержимое
- Проанализирует текст на предмет рисков
- Предоставит подробный отчет с рекомендациями

- Временные файлы автоматически удаляются после обработки
- SSL сертификаты настроены для безопасного соединения

## Поддержка

При возникновении проблем:
1. Проверьте корректность токенов в `.env`
2. Убедитесь, что все зависимости установлены
3. Проверьте логи в консоли при запуске
